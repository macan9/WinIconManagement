# 实现架构

## 1. 核心原则

本项目定位为轻量级 Windows 桌面图标管理工具，采用 **C++ + Win32 原生实现**。

项目继续采用 **Explorer 原生桌面图标** 方案：

- 不自绘桌面图标
- 不替代 Windows 桌面
- 不接管图标双击、右键菜单、文件拖拽等 Explorer 原生行为
- 只负责识别、记录、移动、还原 Explorer 桌面图标坐标
- 使用原生 Win32 浮层窗口绘制矩形分组背景和编辑控件

轻量级是硬约束。常驻状态下应避免托管运行时、大型 UI 框架、高频轮询和持续动画。

## 2. 技术栈

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 主语言 | C++20 | 使用 MSVC 工具链，兼顾现代 C++ 和 Win32 互操作 |
| 应用模型 | Win32 Desktop App | 无托管运行时，常驻内存更小 |
| UI | 原生 Win32 窗口 / Dialog / Property Sheet | 设置页和菜单使用轻量原生控件 |
| 浮层绘制 | Win32 Layered Window + Direct2D 或 GDI+ | 绘制半透明圆角矩形、边框、手柄、hover 背景 |
| 托盘 | `Shell_NotifyIcon` | 系统托盘图标和右键菜单 |
| 图标管理 | Explorer `SysListView32` + ListView 消息 | 读取和设置桌面图标坐标 |
| 鼠标交互 | Win32 消息 + 必要时 `WH_MOUSE_LL` | 框选、拖动、缩放、命中检测 |
| 持久化 | SQLite C API 或 sqlite3 amalgamation | 保存分组、图标位置、快照、设置 |
| 日志 | 轻量滚动文件日志 | 避免引入大型日志框架 |
| 打包 | 单 exe + 必要 dll | 优先绿色启动，后续再补安装器 |

选型边界：

- 不引入托管运行时
- 不引入跨平台重型 UI 框架
- 不引入大体积桌面应用壳
- 不使用会显著增加常驻内存的界面层

这些边界用于保证工具常驻时足够轻量，后续开发计划只围绕原生 Win32 路线推进。

## 3. 性能目标

第一版按轻量常驻工具设计。

| 场景 | 目标 |
| --- | --- |
| 空闲常驻内存 | 10 MB - 40 MB |
| 设置页打开内存 | 20 MB - 70 MB |
| 空闲 CPU | 接近 0%，通常低于 0.1% |
| 框选 / 拖动短时 CPU | 通常低于 3% |
| 启动速度 | 冷启动尽量小于 1 秒 |
| 后台策略 | 事件驱动为主，避免高频轮询 |

性能目标不是绝对承诺，需要按真实机器和 Windows 版本验证。实现上应优先减少常驻对象、窗口数量、定时器和不必要重绘。

│  ├─ DesktopIconService     桌面图标枚举、坐标读取、坐标设置
│  └─ ExplorerMonitor        Explorer 重启和句柄失效检测
├─ Overlay
│  ├─ OverlayWindow          原生透明浮层窗口

## 5. 核心模块

### 5.1 AppController

负责应用生命周期和模块协调。

主要职责：

- 保证单实例运行
- 初始化日志、数据库、托盘、桌面服务和浮层窗口
- 加载用户设置和分组布局
- 协调退出恢复流程
- 释放 Hook、窗口、图标、数据库连接和 GDI/Direct2D 资源
- 处理 Explorer 重启、显示器变化、DPI 变化

实现建议：

- 使用命名互斥体实现单实例
- 使用 RAII 管理 `HWND`、`HICON`、`HMENU`、`HHOOK`、`sqlite3*` 等资源
- 主线程维护 Win32 消息循环
- 耗时操作不要阻塞托盘菜单和窗口消息

### 5.2 TrayIcon

系统托盘使用 `Shell_NotifyIcon` 实现。

第一版菜单：

- 主设置
- 固定 / 取消固定
- 暂停管理
- 恢复原始布局
- 退出

要求：

- 菜单命令使用统一 command id 分发
- 退出时必须调用 `NIM_DELETE`
- Explorer 重启后需要重新添加托盘图标
- 菜单结构保留扩展能力，后续接入快照切换

### 5.3 DesktopWindowResolver

负责找到 Explorer 桌面图标所在的 `SysListView32`。

需要处理的窗口层级：

- `Progman`
- `WorkerW`
- `SHELLDLL_DefView`
- `SysListView32`

预期使用的 Win32 API：

- `FindWindow`
- `FindWindowEx`
- `EnumWindows`
- `GetClassName`
- `GetWindowThreadProcessId`
- `IsWindow`

要求：

- 不永久信任缓存句柄
- 句柄失效时自动重新解析
- 解析失败要记录日志，不让应用崩溃
- 提供“重新连接桌面”命令

### 5.4 DesktopIconService

负责读取和移动 Explorer 原生桌面图标。

主要能力：

- 获取桌面图标数量
- 枚举图标索引
- 读取图标显示名称
- 读取图标坐标
- 设置图标坐标
- 批量移动图标
- 恢复图标原始坐标

预期使用的 ListView 消息：

- `LVM_GETITEMCOUNT`
- `LVM_GETITEMTEXT`
- `LVM_GETITEMPOSITION`
- `LVM_SETITEMPOSITION32`

跨进程注意事项：

- Explorer 和本应用是不同进程
- 读取文本和坐标可能需要在 Explorer 进程分配内存
- 封装 `RemoteBuffer` 管理 `OpenProcess`、`VirtualAllocEx`、`ReadProcessMemory`、`WriteProcessMemory`、`VirtualFreeEx`
- 不能只依赖 ListView index 作为长期身份

### 5.5 OverlayWindow

负责绘制桌面矩形分组背景。

实现方式：

- 创建无边框工具窗口
- 使用 `WS_EX_LAYERED`
- 固定模式下使用 `WS_EX_TRANSPARENT` 让鼠标穿透
- 使用 `WS_EX_NOACTIVATE` 避免抢焦点
- 使用 Direct2D 或 GDI+ 绘制半透明圆角矩形
- 使用局部重绘，避免持续刷新

绘制内容：

- 半透明背景
- 圆角边框
- 分组标题
- 拖动手柄
- 缩放手柄
- hover 高亮
- 图标格子辅助背景

不绘制：

- 真实桌面图标
- 图标文字
- 图标右键菜单
- 图标打开行为

### 5.6 MouseController

负责桌面交互。

主要能力：

- 长按左键框选
- 临时矩形绘制
- 判断图标是否位于框选区域内
- 分组整体拖动
- 分组宽高调整
- 固定和编辑模式切换
- 拖拽结束后触发布局重算

实现策略：

- 优先使用浮层窗口自身的鼠标消息
- 只有在无法可靠捕获桌面拖拽时才使用 `WH_MOUSE_LL`
- Hook 必须按需启用，退出时必须释放
- 鼠标移动中只更新必要区域，不做全屏重绘

### 5.7 FenceLayoutService

负责分组内图标排列和坐标计算。

第一版策略：

- 从左到右、从上到下排列
- 使用桌面图标实际间距计算网格
- 保留进入分组时的顺序
- 分组尺寸不足时提示或纵向扩展

后续扩展：

- 按名称排序
- 按类型排序
- 手动排序
- 快照恢复

### 5.8 Persistence

持久化使用 SQLite C API。

建议表：

```text
AppSettings
- Key
- Value

Fences
- Id
- Name
- X
- Y
- Width
- Height
- IsLocked
- ThemeMode
- BackgroundColor
- Opacity
- CreatedAt
- UpdatedAt

FenceIcons
- Id
- FenceId
- IconIdentity
- DisplayName
- OriginalX
- OriginalY
- CurrentX
- CurrentY
- SortOrder
- LastSeenAt

Snapshots
- Id
- Name
- CreatedAt

SnapshotIcons
- Id
- SnapshotId
- IconIdentity
- DisplayName
- X
- Y
```

`IconIdentity` 第一版可以使用 `DisplayName + Path`。后续增强时再接入 Shell item 标识、快捷方式目标路径和文件属性辅助匹配。

## 6. 核心流程

### 6.1 启动

```text
WinMain
-> 创建单实例互斥体
-> 初始化 Logger
-> 初始化 SQLite
-> 初始化 AppController
-> 创建托盘图标
-> 解析桌面 SysListView32
-> 加载上次分组配置
-> 创建原生浮层窗口
-> 将已托管图标移动到分组内
-> 进入 Win32 消息循环
```

### 6.2 框选创建分组

```text
用户在桌面拖动创建矩形
-> MouseController 生成临时框选区域
-> DesktopIconService 枚举当前桌面图标
-> DragSelection 判断命中图标
-> Persistence 记录原始坐标
-> FenceLayoutService 计算分组内坐标
-> DesktopIconService 批量移动图标
-> OverlayWindow 绘制分组背景
-> Persistence 保存分组和图标关系
```

### 6.3 退出

```text
用户点击托盘退出
-> AppController 标记正在退出
-> 停止 Hook 和交互
-> 读取托管图标原始坐标
-> DesktopIconService 恢复图标位置
-> 销毁浮层窗口
-> Shell_NotifyIcon(NIM_DELETE)
-> 关闭数据库和日志
-> 释放所有 Win32 资源
-> 进程退出
```

### 6.4 再次启动恢复

```text
应用启动
-> 加载分组配置
-> 枚举桌面图标
-> 匹配托管图标
-> 创建浮层窗口
-> 重新应用分组布局
-> 缺失图标标记为 missing
```

### 6.5 Explorer 重启恢复

```text
检测到 Explorer 或桌面 ListView 句柄失效
-> 清空旧句柄
-> 延迟重试解析桌面窗口
-> 重新添加托盘图标
-> 重新枚举图标
-> 重新应用当前分组布局
-> 刷新浮层窗口层级
```

## 7. Hover 能力边界

采用 Explorer 原生图标后，hover 效果以浮层辅助视觉为主。

可以稳定实现：

- Explorer 原生图标 hover 高亮
- 分组背景 hover 变亮
- 分组边框 hover 变色
- 图标格子辅助背景
- 编辑模式下显示拖动和缩放手柄

不作为第一版目标：

- 图标本体缩放
- 图标本体阴影
- 图标本体发光
- 图标复杂动画

这些效果需要自绘图标或截图镜像浮层，会破坏轻量和原生行为边界。

## 8. 难点和风险

### 8.1 跨进程 ListView 操作

桌面图标由 Explorer 进程管理，读取文本和坐标时要处理跨进程内存。

应对方式：

- 独立封装 `RemoteBuffer`
- 所有 Win32 调用检查返回值
- 失败时写诊断日志
- 不让单个图标失败中断整个流程

### 8.2 桌面窗口层级变化

Explorer 重启、主题变化、系统升级后，桌面窗口结构可能变化。

应对方式：

- 封装 `DesktopWindowResolver`
- 失败后延迟重试
- 提供手动重新连接入口
- 保留详细窗口类名诊断日志

### 8.3 多显示器和 DPI

坐标需要在桌面物理像素、窗口坐标、DPI 感知之间保持一致。

应对方式：

- 进程设置 Per-Monitor DPI Aware
- 持久化坐标统一使用桌面物理像素
- 浮层绘制时做 DPI 转换
- 测试 100%、125%、150% 缩放

### 8.4 浮层窗口层级和穿透

浮层既要可见，又不能破坏 Explorer 原生图标操作。

应对方式：

- 固定模式启用鼠标穿透
- 编辑模式只在背景、边框、手柄区域响应鼠标
- 图标区域尽量交还 Explorer
- 提供暂停管理入口

### 8.5 异常退出恢复

异常退出后图标可能停留在分组区域。

应对方式：

- 移动前记录原始坐标
- 启动时检测上次是否异常退出
- 托盘提供“恢复原始布局”
- 快照作为额外恢复点

## 9. 开发阶段

### 第一阶段：原生骨架和托盘

- C++ Win32 项目初始化
- 单实例
- 消息循环
- 轻量日志
- 托盘图标和菜单
- 完整退出清理

### 第二阶段：Explorer 图标控制 PoC

- 解析桌面 `SysListView32`
- 枚举图标
- 读取名称和坐标
- 移动图标
- 还原图标

### 第三阶段：持久化和浮层

- SQLite 数据模型
- 原生透明浮层窗口
- 分组背景绘制
- 固定 / 编辑模式
- 坐标转换

### 第四阶段：单分组创建和闭环

- 桌面框选
- 图标命中
- 创建单个分组
- 单分组图标自动排列
- 单分组退出恢复
- 单分组再次启动重建

### 第五阶段：多分组运行时和数据管理

- 多分组创建与显示
- 当前分组和分组集合状态
- 多分组退出恢复与再次启动恢复
- 分组删除、更新、重排的数据接口

### 第六阶段：设置、稳定性和视觉增强

- 设置窗口
- 分组拖动和缩放
- 开机自启动
- Explorer 重启恢复
- 多显示器和 DPI 适配
- 失效图标清理

- 桌面快照
- 快速切换
- 排序选项
- hover 辅助背景
- 分组主题色

## 10. 第一版边界

第一版必须完成：

- 原生 C++ Win32 常驻 exe
- 托盘图标和右键菜单
- Explorer 原生桌面图标枚举
- 图标坐标读取和移动
- 原生浮层矩形背景
- 框选创建分组
- 退出恢复原始图标位置
- 再次启动恢复分组布局

第一版不做：

- 自绘桌面图标
- 托管 UI 框架
- 图标本体动画
- 复杂主题系统
- 跨虚拟桌面同步
- 重型插件体系

这个边界可以让项目保持轻量，同时先完成桌面图标管理的核心闭环。
