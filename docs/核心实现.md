双击启动一个 exe 应用，可以去管理、分类、美化 Windows 桌面图标，产品方向类似 Fences。

1. 启动 exe 后，系统托盘出现应用图标。托盘右键功能至少包括：主设置、固定/取消固定、退出。后续菜单能力要保留扩展性，退出流程必须完整不残留。
2. 启动 exe 后，用户可以在 Windows 桌面空白区长按鼠标左键拖动，绘制矩形区域。第一阶段先把“创建一个分组”做稳，再扩展到连续创建多个分组。
3. 应用最终需要支持绘制多个矩形分组，而不是只支持一个。多个分组需要各自保存位置、尺寸、样式和图标关系。
4. 退出 exe 后，先保证单分组托管图标可以恢复并删除对应矩形背景；再次启动 exe 后先保证单分组闭环，再扩展到全部分组统一恢复。
5. 矩形区域样式说明：半透明背景、可配置透明度、带圆角，支持浅色模式和深色模式，后续扩展自定义颜色。
6. 矩形区域功能说明：支持调整宽高、整体拖动、位置和尺寸固定；支持矩形内图标拖动并在拖拽后自动排序；尽量保留 Windows 图标原生能力，包括拖拽打开和原生右键；后续可扩展轻量 hover 样式。
7. 主设置界面需要支持多分组管理，至少包括：固定/取消固定、暂停管理、深色/浅色切换、开机自启动，以及多分组列表、重命名、删除、排序等能力。
8. 后续扩展功能包括：桌面快照、快速切换、更多分组视觉增强。
