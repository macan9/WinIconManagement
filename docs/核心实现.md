双击启动一个exe应用，可以去管理、分类、美化win桌面图标，类似于Fences

1. 启动exe后，系统托盘出现应用图标，托盘图标右键功能包括：主设置，固定/取消固定，退出。
   要求保留右键菜单的扩展性，退出app功能完整不残留。
2. 启动exe后，在Windows桌面长按鼠标左键拖动，绘制一块矩形区域，会自动选中桌面图标，先记录当前桌面图标位置，然后将桌面图标移动到我的框选区域内，自动对齐图标
3. 退出exe后，还原图标位置，删除矩形背景；再次启动exe，生成矩形背景，再将对应图标移动到矩形背景内，实现功能闭环
4. 矩形区域样式说明：半透明背景，可以设置透明度，带圆角，支持浅色模式和深色模式，后续扩展自定义颜色
5. 矩形区域功能说明：支持调整矩形宽高、整体拖动和位置宽高固定；支持矩形内图标拖动功能，拖拽完成后会自动在矩形内排序；保留win图标的原生功能，支持拖拽打开，支持Windows图标的原生右键功能；支持特殊hover样式，比如图标轻微放大，图标阴影
6. 主设置界面包括：固定和取消固定切换，深色浅色切换，开机自启动等
7. 后续功能：桌面快照和快速切换
