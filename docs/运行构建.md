# 运行与构建

## 1. 适用范围

本文用于本项目当前阶段（C++20 + Win32 + CMake + Ninja）本地开发运行。

## 2. 先准备终端环境

普通 PowerShell 默认没有加载 MSVC 环境变量，先执行：

```powershell
cmd /s /c """D:\Program Files\Microsoft Visual Studio\18\Community\VC\Auxiliary\Build\vcvars64.bat"" >nul && powershell"
```

会打开一个新的 PowerShell 窗口。后续命令都在这个新窗口执行。

快速验证：

```powershell
cl
cmake --version
ninja --version
```

## 3. 首次构建

在项目根目录执行：

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

## 4. 运行程序

构建完成后运行：

```powershell
.\build\WinIconManagement.exe
```

程序启动后会显示主窗口，并在系统托盘出现图标。

## 5. 日常增量构建

代码改动后只需要：

```powershell
cmake --build build
```

## 6. Release 构建

如果需要单独构建 Release：

```powershell
cmake -S . -B build-release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
.\build-release\WinIconManagement.exe
```

## 7. 清理并重建

```powershell
Remove-Item -Recurse -Force .\build
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

## 8. VS Code 调试运行

在已加载 MSVC 环境的终端里打开工程：

```powershell
code .
```

然后在 VS Code 中：

1. `CMake: Configure`
2. `CMake: Build`
3. `F5` 启动调试

## 9. 日志位置

运行日志默认输出到：

```text
%LOCALAPPDATA%\WinIconManagement\logs\app.log
```

快速查看最后 30 行：

```powershell
Get-Content "$env:LOCALAPPDATA\WinIconManagement\logs\app.log" -Tail 30
```

## 10. 常见问题

`cl` 找不到：

- 原因：终端没加载 `vcvars64.bat`
- 处理：重新执行第 2 节命令

`cmake` 找不到：

- 原因：当前终端没有加载 VS 自带 CMake 路径
- 处理：重新执行第 2 节命令

程序运行后看不到托盘图标：

- 先看日志是否出现 `Tray icon added.`
- 如果没有，先确认构建的是最新代码，再重启程序
