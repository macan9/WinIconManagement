# 00 计划总览

## 当前主线结论

项目采用 **Explorer 控制主导**：桌面图标继续由 Explorer 的 `SysListView32` 原生管理和绘制，应用负责 Fence 数据、布局、编辑、恢复和背景控制。

关键顺序已经调整：

1. 先有基础底座。
2. 再证伪并止血外部窗口背景路线。
3. 再实现 Explorer Bridge 进程内背景。
4. 再收口 Overlay 输入边界。
5. 最后才做框选创建单 Fence 的产品闭环。

这样可以避免在真实背景路径未稳定前，把“创建 Fence”误当成已经完成产品闭环。
