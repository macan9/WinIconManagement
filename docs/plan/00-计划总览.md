# 计划总览

## 总目标

本项目采用 **Explorer 控制主导** 方案实现桌面分组能力。

目标不是自绘一套新的桌面图标系统，而是：

- 保持桌面图标仍由 `Explorer / SysListView32` 原生绘制
- 应用负责 `Fence` 分组背景、标题、编辑控件和规则管理
- 应用负责图标与分组的归属关系、目标坐标、自动排布与恢复
- 应用在不破坏 Windows 原生桌面交互的前提下，实现接近市面上 `Fences` 软件的体验

一句话定义：

`Windows 继续画图标，我们负责控制图标属于哪个 Fence、在 Fence 内怎么排、何时恢复、如何编辑 Fence。`

## 主线验收口径

最终完成时，应满足：

1. 桌面图标仍由 Windows 原生绘制。
2. 图标视觉上稳定地落在 Fence 区域之上。
3. Fence 的绘制不破坏桌面、任务栏、托盘、普通窗口的右键和点击。
4. 应用能稳定维护图标与 Fence 的归属和布局。
5. 启动、退出、Explorer 重启、异常退出后都能恢复到正确状态。
