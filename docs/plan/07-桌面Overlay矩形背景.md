# 07 桌面 Overlay 矩形背景

## 目标

实现桌面上的透明矩形分组背景，用于承载分组视觉和后续拖动、缩放交互。

## 开发内容

- 创建透明无边框 WPF Overlay 窗口
- 绘制矩形分组背景
- 支持圆角、边框、透明度
- 支持浅色 / 深色样式
- 支持分组 hover 高亮
- 支持固定模式下隐藏编辑控件
- 支持窗口位置和桌面坐标换算
- 初步处理多显示器区域

## 产出物

- `DesktopOverlay`
- `FenceView`
- 透明矩形背景显示能力

## 验收标准

- 应用启动后能在桌面显示矩形背景
- 背景不会挡住桌面图标双击和右键
- 固定模式下 Overlay 尽量鼠标穿透
- 深色 / 浅色样式可以切换
- 退出后 Overlay 完整消失

## 风险点

- Overlay 层级可能压住 Explorer 图标
- 鼠标穿透和编辑交互之间需要切换
- WPF 设备无关像素和桌面物理像素需要统一
