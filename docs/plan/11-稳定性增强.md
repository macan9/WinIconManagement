# 11 稳定性增强

## 目标

处理日常使用中的关键稳定性问题，让应用能适应 Explorer 重启、多显示器、DPI 变化和桌面图标变化。

## 开发内容

- 监听 Explorer 进程重启
- 桌面 ListView 句柄失效后自动重连
- Explorer 重启后重新添加托盘图标
- 监听显示器变化
- 监听 DPI 变化
- 重新计算浮层窗口位置
- 重新应用分组布局
- 处理桌面图标新增、删除、重命名
- 提供失效图标清理能力
- 提供“暂停管理”
- 提供“重新连接桌面”
- 增加关键操作性能日志

## 产出物

- Explorer 重启恢复能力
- 多显示器和 DPI 适配
- 图标变化处理机制
- 诊断与恢复入口
- 性能和错误日志

## 验收标准

- 重启 Explorer 后应用能恢复桌面连接
- 重启 Explorer 后托盘图标能恢复
- 改变显示器缩放后浮层和图标位置基本正确
- 插拔显示器后应用不崩溃
- 删除已托管图标后应用能识别缺失状态
- 用户可以手动重新连接桌面

## 风险点

- 多显示器坐标体系复杂，需要大量实机测试
- Explorer 重启恢复时机过早可能失败，需要重试机制
- 桌面图标变化事件不一定可靠，可能需要低频校验
