# 12 快照与视觉增强

## 目标

在核心闭环稳定后，增加桌面快照、快速切换和轻量视觉增强能力。

## 开发内容

- 实现当前桌面布局快照保存
- 实现快照列表
- 实现快照快速切换
- 支持快照重命名和删除
- 支持分组内排序选项：
  - 默认顺序
  - 按名称
  - 按类型
- 增加图标格子 hover 背景
- 增加拖拽目标占位效果
- 增加分组背景轻量动画
- 支持自定义主题颜色

## 产出物

- 快照管理能力
- 快速切换桌面布局能力
- 更完整的视觉体验

## 验收标准

- 可以保存当前桌面布局为快照
- 可以从快照恢复桌面图标位置
- 快照缺失图标时有明确提示或日志
- 图标格子 hover 不影响原生双击和右键
- 视觉增强不会破坏核心图标管理流程

## 风险点

- 快照恢复和当前分组状态可能冲突，需要定义优先级
- 视觉增强不能演变成自绘图标方案
- Hover 辅助层需要和真实图标坐标保持同步
