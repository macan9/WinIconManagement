# 08 框选创建分组

## 目标

实现用户在桌面长按左键拖动框选区域，并将区域内图标收纳到新分组中的核心体验。

## 开发内容

- 实现桌面鼠标监听
- 判断长按左键拖动行为
- 绘制临时框选矩形
- 枚举当前桌面图标
- 根据图标坐标判断是否命中框选区域
- 创建分组记录
- 记录命中图标原始位置
- 计算分组内网格位置
- 将图标移动到分组内
- 保存分组和图标关系

## 产出物

- 框选创建分组能力
- 第一个完整图标收纳闭环

## 验收标准

- 用户能通过拖拽在桌面创建矩形区域
- 框选区域内图标能被识别
- 被选中图标能移动到矩形区域内并自动排列
- 分组背景能保存并显示
- 未选中的图标不受影响

## 风险点

- 框选操作不能破坏 Explorer 原生拖选体验太多
- 图标命中判断需要考虑图标尺寸和文本区域
- 自动排列需要处理分组尺寸不足的情况
