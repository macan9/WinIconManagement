# 09-1 外部窗口背景路线止血与收口

## 目标

把外部窗口背景路线收成安全状态：

`宁可背景不显示，也不能遮住桌面、图标、任务栏或普通窗口。`

## 安全规则

- `BackgroundWindow` 不允许主动 `ShowWindow` Explorer 宿主。
- `BackgroundWindow` 不允许 resize Explorer 的 `WorkerW / Progman / SHELLDLL_DefView`。
- 没有天然安全宿主时必须 fail closed。
- `Progman`、`SHELLDLL_DefView`、异常 `WorkerW` 不作为真实背景主路径。
- Overlay 不绘制真实背景填充。
- Overlay 不绑定异常 Explorer host 进行全屏 Z 序调整。

## 验收标准

- 启动应用后没有全屏白幕。
- 任务栏、托盘、普通窗口不被遮挡。
- 桌面右键、图标点击、图标拖动不被背景层破坏。
- 没有安全宿主时日志明确显示背景不可用。
- 后续真实背景绘制转入 `10`，不再回到外部窗口试错。
