# 07 桌面图标移动与还原验证

## 目标

验证主程序可以稳定控制 Explorer 原生桌面图标坐标，并能在失败或退出时恢复。

这是 Explorer 控制主导方案的核心能力之一。

## 核心能力

- 根据 icon index 或 identity 找到目标图标。
- 通过 `SysListView32` 设置图标位置。
- 批量移动一组图标。
- 保存移动前坐标。
- 失败时回滚已移动图标。
- 按恢复策略还原图标。

## 与 Fence 的关系

创建 Fence 时：

1. 框选命中图标。
2. 计算 Fence bounds。
3. 计算图标在 Fence 内的目标布局。
4. 移动图标。
5. 持久化 Fence 与 FenceIcon。

Bridge 只负责画背景，不参与图标移动。

## 安全要求

- 批量移动必须可回滚。
- Explorer 不可访问时中止。
- 部分移动失败时回滚成功项。
- 不在 Explorer 重启期间继续发送 ListView 消息。
- 移动节奏不能让 Explorer UI 卡死。

## 验收标准

- 单个图标可移动并还原。
- 多个图标可批量移动并还原。
- 失败时不会留下半移动状态。
- Explorer 重启后移动逻辑自动暂停并等待重连。
- 移动结果能被持久化层记录。
