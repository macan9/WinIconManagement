# 07 桌面图标移动、批量布局与安全恢复

## 目标

验证应用可以稳定控制 Explorer 原生桌面图标的坐标，并能把一批图标安全移动到目标区域，再按记录恢复到原始位置。

这是 Explorer 控制主导方案的核心能力验证阶段。

## 开发内容

- 实现单个图标坐标设置
- 实现批量图标坐标设置
- 实现按目标区域的规则布局
- 移动前记录原始坐标
- 实现一键恢复原始坐标
- 刷新桌面 ListView 状态
- 增加移动失败日志
- 增加基础保护：
  - 找不到图标不移动
  - 坐标无效不移动
  - ListView 句柄失效时重连
  - Explorer 进程不可访问时中止

## 重点要求

本阶段不是为了做完整 Fence，而是为了确认：

- 我们能稳定“控制”图标位置
- 我们能批量做布局
- 我们能安全恢复

三者缺一不可。

## 产出物

- 图标坐标设置能力
- 批量布局能力
- 原始坐标恢复能力
- 最小可验证 PoC

## 验收标准

- 能批量移动多枚桌面图标
- 能把已移动图标恢复到移动前位置
- 批量移动后桌面不会出现明显错乱
- 失败时有明确日志
- Explorer 重启后不会继续使用失效句柄

## 风险点

- `LVM_SETITEMPOSITION32` 的行为在不同环境下可能存在差异
- Windows 自动排列设置可能干扰结果
- 批量操作节奏过快可能导致 Explorer 响应异常

## 与主线关系

本阶段是后续“图标进入 Fence 区域”和“退出时恢复桌面布局”的直接前置条件。
