# 13-2 单 Fence 编辑提交闭环

## 目标

完成单 Fence 的编辑提交和持久化闭环。

## 范围

- 重命名提交。
- 删除 Fence，并明确图标去向。
- 移动 Fence，并同步图标目标坐标。
- 缩放 Fence，并重新计算图标布局。
- 提交失败时回滚运行时状态和数据库状态。

## 关键要求

- 运行时状态、Explorer 图标位置、数据库记录尽量同步提交。
- 失败不能留下半成功状态。
- 删除后的图标恢复规则必须明确。

## 验收标准

- 用户可以稳定重命名当前 Fence。
- 用户可以稳定删除当前 Fence。
- 用户可以稳定移动和缩放当前 Fence。
- 图标布局变化与 Fence 几何变化一致。
- 重启后名称、位置、尺寸、图标关系仍一致。
