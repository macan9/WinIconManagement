# 11-1 真实 Fence 背景绘制最小闭环

## 目标

在 `11-0` 已经解决宿主与层级锚定的前提下，补齐第一版“真正能看见”的 Fence 背景绘制闭环。

本阶段只关注：

- 背景矩形真的画出来
- 位置和尺寸是对的
- 刷新与重连后还能稳定重绘

## 本阶段只做什么

- 为真实背景层接入 Fence 几何数据
- 绘制最小可用的背景矩形和边框
- 处理创建后首次显示
- 处理刷新与重绘
- 处理 Explorer 重连后的重新显示

## 本阶段不做什么

- 不追求完整标题、活动态、编辑态
- 不收口前景提示与交互热区
- 不收口编辑提交逻辑

## 验收标准

- 创建单 Fence 后，真实背景能立刻显示
- 背景位置、大小与 Fence 数据一致
- 再次刷新、重启 Explorer 后仍能恢复显示
- 不再依赖“下一次操作”才把背景补出来

## 执行顺序

1. 接入背景层消费的 Fence 几何与样式数据。
2. 实现第一版背景矩形绘制。
3. 验证创建后首次显示。
4. 验证刷新、重连和重绘稳定性。
