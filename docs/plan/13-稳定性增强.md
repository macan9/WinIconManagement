# 11 稳定性增强

## 目标

处理日常使用中的关键稳定性问题，让应用能适应 Explorer 重启、多显示器、DPI 变化和桌面图标变化。

稳定性增强阶段默认建立在 `10-11` 已完成之后，也就是：

- 单分组闭环已经稳定
- 多分组运行时和数据管理已经稳定
- 多分组设置与编辑入口已经可用

## 开发内容

- 监听 Explorer 进程重启
- 桌面 ListView 句柄失效后自动重连
- Explorer 重启后重新添加托盘图标
- 监听显示器变化
- 监听 DPI 变化
- 重新计算浮层窗口位置
- 重新应用全部分组布局
- 处理桌面图标新增、删除、重命名
- 提供失效图标清理能力
- 提供“暂停管理”
- 提供“重新连接桌面”
- 增加关键操作性能日志

## 多分组要求

- Explorer 重启后要恢复全部分组，而不是只恢复最后一个
- 显示器变化后要重新校正全部分组矩形
- DPI 变化后要重新计算全部分组的像素边界
- 手动“重新连接桌面”后要重新应用全部分组布局
- 清理失效图标时要能定位其所属分组

## 产出物

- Explorer 重启恢复能力
- 多显示器和 DPI 适配
- 图标变化处理机制
- 诊断与恢复入口
- 性能和错误日志

## 验收标准

- 重启 Explorer 后应用能恢复桌面连接
- 重启 Explorer 后托盘图标能恢复
- 重启 Explorer 后全部分组背景和布局能恢复
- 改变显示器缩放后全部分组和图标位置基本正确
- 插拔显示器后应用不崩溃
- 删除已托管图标后应用能识别缺失状态
- 用户可以手动重新连接桌面

## 风险点

- 多显示器坐标体系复杂，需要大量实机测试
- Explorer 重启恢复时机过早可能失败，需要重试机制
- 多分组下恢复、重排、重绘的失败范围更大，需要分组级诊断信息
