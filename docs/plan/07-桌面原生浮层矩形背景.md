# 07 桌面原生浮层矩形背景

## 目标

实现轻量原生透明浮层窗口，用于绘制桌面矩形分组背景、边框、标题和编辑手柄。

## 开发内容

- 创建无边框工具窗口
- 设置窗口扩展样式：
  - `WS_EX_LAYERED`
  - `WS_EX_TOOLWINDOW`
  - `WS_EX_NOACTIVATE`
  - 固定模式下使用 `WS_EX_TRANSPARENT`
- 使用 Direct2D 或 GDI+ 绘制：
  - 半透明矩形背景
  - 圆角
  - 边框
  - 分组标题
  - 拖动手柄
  - 缩放手柄
  - hover 高亮
- 实现固定模式和编辑模式
- 实现局部重绘，避免持续刷新
- 处理多显示器桌面区域
- 处理 DPI 坐标转换

## 产出物

- `OverlayWindow`
- `FenceRenderer`
- 原生透明矩形背景显示能力
- 固定 / 编辑模式切换

## 验收标准

- 应用启动后能在桌面显示矩形背景
- 背景不会挡住桌面图标双击和右键
- 固定模式下浮层鼠标穿透
- 编辑模式下边框和手柄可交互
- 退出后浮层窗口完整销毁

## 风险点

- 浮层窗口层级可能压住 Explorer 图标
- 分层窗口透明绘制需要控制重绘成本
- DPI 和物理像素坐标必须统一
