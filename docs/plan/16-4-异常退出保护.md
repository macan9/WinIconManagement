# 16-4 异常退出保护

## 目标

处理应用崩溃、被强制结束、系统断电等异常路径，避免用户误以为桌面图标丢失或布局不可恢复。

## 开发内容

- 启动时写入运行中标记
- 正常退出时清理运行中标记
- 启动时检测上次是否异常退出
- 异常退出后优先进入安全恢复流程
- 保存最近一次可恢复快照
- 提供恢复失败的诊断日志

## 验收标准

- 强制结束进程后再次启动能检测异常退出
- 异常恢复不会覆盖最近可用状态
- 恢复失败时有清晰日志
- 用户桌面不会进入不可理解的半恢复状态

## 风险点

- 异常退出时内存状态丢失，只能依赖最后一次持久化状态
- 如果快照写入不及时，恢复依据可能滞后
