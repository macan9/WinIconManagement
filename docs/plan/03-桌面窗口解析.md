# 03 桌面窗口解析

## 目标

稳定找到 Windows Explorer 桌面图标所在的 `SysListView32` 控件，为读取和移动桌面图标做准备。

## 开发内容

- 封装 `DesktopWindowResolver`
- 查找桌面相关窗口：
  - `Progman`
  - `WorkerW`
  - `SHELLDLL_DefView`
  - `SysListView32`
- 支持 Explorer 重启后的重新解析
- 记录窗口句柄和解析过程日志
- 提供诊断接口：
  - 当前是否连接到桌面 ListView
  - 当前 ListView 句柄
  - 最近一次解析失败原因

## 产出物

- `DesktopWindowResolver`
- 桌面 ListView 句柄获取能力
- 失败重试和日志记录

## 验收标准

- 应用启动后能找到桌面 `SysListView32`
- Explorer 重启后可以重新找到句柄
- 找不到桌面窗口时不会导致应用崩溃
- 日志中能看到解析结果

## 风险点

- 不同 Windows 版本桌面窗口层级可能不同
- 多显示器和虚拟桌面可能影响窗口发现逻辑
- Explorer 重启时旧句柄会失效，不能缓存后永久使用
