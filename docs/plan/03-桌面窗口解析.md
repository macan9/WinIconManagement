# 03 桌面窗口解析

## 目标

稳定找到 Windows Explorer 桌面图标所在的 `SysListView32` 控件，为读取和移动桌面图标做准备。

## 开发内容

- 封装 `DesktopWindowResolver`
- 查找桌面相关窗口：
  - `Progman`
  - `WorkerW`
  - `SHELLDLL_DefView`
  - `SysListView32`
- 使用 `EnumWindows` 处理不同桌面窗口层级
- 校验窗口句柄有效性
- 记录窗口类名、句柄、进程 id 等诊断信息
- 支持 Explorer 重启后的重新解析
- 提供“重新连接桌面”接口

## 产出物

- `DesktopWindowResolver`
- 桌面 ListView 句柄获取能力
- 句柄失效检测能力
- 解析日志和诊断信息

## 验收标准

- 应用启动后能找到桌面 `SysListView32`
- Explorer 重启后能重新找到句柄
- 找不到桌面窗口时应用不崩溃
- 日志中能看到解析路径和失败原因

## 风险点

- 不同 Windows 版本的桌面窗口层级可能不同
- 旧句柄失效后不能继续使用
- 虚拟桌面和多显示器可能影响窗口发现结果
