# 11-0 桌面背景层宿主与层级锚定

## 目标

先只解决一个最底层的问题：

`真实 Fence 不能继续依赖 Overlay 充当背景层。`

本阶段只负责把真实 Fence 背景层挂到正确的桌面宿主链路上，并确认它和桌面图标的前后层级关系是正确的。

## 本阶段只做什么

- 明确真实背景层的宿主窗口选择策略
- 明确背景层与 Overlay 的职责边界
- 落地第一版真实背景层窗口骨架
- 处理 Explorer 重连后的重新挂接
- 验证图标视觉上不再被“假背景层”盖住

## 本阶段不做什么

- 不追求背景层的完整视觉样式
- 不收口标题、活动态、编辑态提示
- 不收口移动、缩放、删除、重命名
- 不扩展到多 Fence 完整管理

## 关键问题

- 真实背景层应该附着到哪个桌面宿主
- 它如何保持在桌面图标之下或与桌面层级关系正确
- Explorer 重启或桌面句柄失效后如何重新锚定
- 如何避免为了下沉层级而破坏桌面输入链

## 验收标准

- 真实 Fence 背景不再由全屏 Overlay 直接填充
- 桌面图标视觉上不再像被半透明遮罩压住
- 背景层重连后仍能重新挂回桌面宿主
- 任务栏、托盘、普通窗口、桌面右键不被破坏

## 执行顺序

1. 复盘当前 Overlay 直接充当背景层的层级问题。
2. 定义背景层宿主窗口选择与回退策略。
3. 落地真实背景层窗口骨架与生命周期。
4. 接入 Explorer 重连后的重新锚定。
5. 做单 Fence 层级正确性的人工验证。
