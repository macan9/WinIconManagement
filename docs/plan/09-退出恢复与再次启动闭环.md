# 09 退出恢复与再次启动闭环

## 目标

完成应用退出后恢复原始桌面图标位置、再次启动后重建分组布局的闭环。

## 开发内容

- 退出时读取托管图标原始坐标
- 将托管图标恢复到原始位置
- 停止鼠标 Hook 和交互状态
- 销毁所有原生浮层窗口
- 删除托盘图标
- 关闭 SQLite 数据库
- 释放 Win32 资源
- 启动时读取上次分组配置
- 启动时重新枚举桌面图标
- 匹配已托管图标
- 重建矩形背景
- 将匹配图标重新移动到分组内
- 处理缺失图标
- 增加异常退出检测

## 产出物

- 退出恢复流程
- 再次启动恢复流程
- 异常退出后的恢复入口

## 验收标准

- 正常退出后图标恢复到原始位置
- 正常退出后矩形背景消失
- 正常退出后托盘图标消失
- 再次启动后矩形背景重新出现
- 再次启动后对应图标重新进入分组
- 缺失图标不会阻塞应用启动

## 风险点

- 恢复失败可能导致用户桌面布局混乱
- 图标身份匹配不稳定会影响重启恢复
- 异常退出后需要给用户手动恢复能力
