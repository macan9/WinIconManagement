# 05 桌面图标移动与还原验证

## 目标

验证可以将 Explorer 原生桌面图标移动到指定坐标，并能恢复到原位置。

## 开发内容

- 实现单个图标移动
- 实现批量图标移动
- 移动前记录原始坐标
- 实现一键恢复原始坐标
- 刷新桌面 ListView 状态
- 增加移动失败日志
- 增加基础保护：
  - 找不到图标不移动
  - 坐标无效不移动
  - ListView 句柄失效时重新解析
  - Explorer 进程不可访问时中止操作

## 产出物

- 图标坐标设置能力
- 原始坐标恢复能力
- 最小可验证 PoC

## 验收标准

- 能选择一个测试图标移动到指定位置
- 能将测试图标恢复到移动前位置
- 批量移动后桌面不会出现明显错乱
- Explorer 重启后不会继续使用失效句柄
- 移动失败有明确日志

## 风险点

- `LVM_SETITEMPOSITION32` 在不同 Windows 环境下表现需要实测
- Windows 自动排列图标设置可能干扰移动结果
- 批量移动需要控制节奏，避免 Explorer 响应异常
