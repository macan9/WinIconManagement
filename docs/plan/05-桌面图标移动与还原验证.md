# 05 桌面图标移动与还原验证

## 目标

验证可以将 Explorer 原生桌面图标移动到指定坐标，并能恢复到原位置。

## 开发内容

- 实现单个图标移动
- 实现批量图标移动
- 移动前记录原始坐标
- 实现一键恢复原始坐标
- 刷新桌面 ListView 状态
- 增加移动失败日志
- 增加基础保护：
  - 找不到图标不移动
  - 坐标无效不移动
  - ListView 句柄失效时重新解析
  - Explorer 进程不可访问时中止操作

## 产出物

- 图标坐标设置能力
- 原始坐标恢复能力
- 最小可验证 PoC

## 验收标准

- 能执行“批量网格移动”并完成多图标移动（不再仅单点验证）
- 能将已移动图标恢复到移动前位置
- 批量移动后桌面不会出现明显错乱
- Explorer 重启后不会继续使用失效句柄
- 移动失败有明确日志

## 风险点

- `LVM_SETITEMPOSITION32` 在不同 Windows 环境下表现需要实测
- Windows 自动排列图标设置可能干扰移动结果
- 批量移动需要控制节奏，避免 Explorer 响应异常

## 当前实现说明（PoC）

- 已新增 `DesktopIconService` 能力：
  - `SetDesktopIconPosition`
  - `MoveDesktopIcons`
  - `RefreshDesktopIcon`
  - `CanAccessExplorerProcess`
- 已加入基础保护：
  - `listView` 句柄无效时不移动
  - `explorerPid` 无效或进程不可访问时不移动
  - 坐标超出 `[-32768, 32767]` 时不移动
  - 单个图标失败不影响批量流程
- 已接入托盘最小验证命令：
  - `批量网格移动`：按可见网格批量计算目标点并移动图标，同时记录原始快照
  - `恢复原始布局`：按原始快照批量恢复
- 日志关键字：
  - `[DesktopMove]`
  - `[DesktopIcons]`

## 批量移动策略增强（05）

- 目标点生成从“单图标固定点”升级为“可见网格批量目标点”：
  - 基于当前图标坐标检测主轴间距（异常值回退到系统 `SM_CXICONSPACING/SM_CYICONSPACING`）
  - 在虚拟桌面可见区域内计算网格起点、行列、容量
  - 采用列优先（column-major）分配目标点，保证批量有序
- 增加边界与容量保护：
  - 目标点始终钳制在可见工作区边界内
  - 当图标数超过当前网格容量时，仅规划可容纳部分并记录 `skipped`
- 增加可观测性：
  - 日志新增 `[DesktopMove] bulk grid result`，包含 `moved/expected/skipped/origin/spacing/grid/capacity`
  - 主窗口状态区新增“批量移动摘要”，便于快速核查策略是否生效
