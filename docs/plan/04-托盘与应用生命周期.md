# 04 托盘与应用生命周期

## 目标

实现常驻桌面工具的生命周期控制：启动、隐藏、托盘菜单、退出和 Explorer 重启后的基础恢复。

该阶段是后续 Bridge 注入和恢复策略的外层壳。

## 核心能力

- 创建主窗口。
- 创建托盘图标。
- 支持打开主窗口。
- 支持隐藏到托盘。
- 支持从托盘退出。
- 监听 `TaskbarCreated`，Explorer 重启后重建托盘图标。
- 启动时初始化日志、路径、数据库和基础状态。
- 退出时按顺序清理 Overlay、BackgroundWindow、Bridge、托盘和窗口资源。

## 生命周期原则

- 应用退出必须是可恢复、可重复的。
- 清理顺序必须明确，不能让 Overlay 或 BackgroundWindow 残留在桌面。
- 后续 Bridge 接入后，退出时必须优先通知 Bridge 清理 Explorer 内状态。
- Explorer 重启时不要继续使用旧的窗口句柄、旧 ListView 或旧 Bridge 状态。

## 托盘菜单建议

第一版保留最小菜单：

- Show
- Reconnect Explorer
- Pause/Resume
- Exit

后续可加入：

- Bridge Status
- Clear Fence Background
- Diagnostics

## 本阶段不做

- 不实现图标移动。
- 不实现 Fence 创建。
- 不实现真实背景绘制。
- 不实现 Explorer 注入。

## 验收标准

- 应用启动后托盘图标可见。
- 主窗口可打开和隐藏。
- 托盘退出后进程结束。
- 退出后无 Overlay、BackgroundWindow 或主窗口残留。
- Explorer 重启后托盘图标可以重建。
