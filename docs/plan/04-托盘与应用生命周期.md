# 02 托盘与应用生命周期

## 目标

实现常驻型桌面工具的托盘入口、右键菜单与完整生命周期控制，为 Explorer 桌面控制主线提供统一入口。

## 开发内容

- 使用 `Shell_NotifyIcon` 添加托盘图标
- 封装 `TrayIcon`
- 注册托盘消息窗口
- 实现托盘右键菜单，至少包含：
  - 主设置
  - 固定控制 / 取消固定控制
  - 重新连接桌面
  - 恢复桌面布局
  - 退出
- 统一菜单 `command id` 分发
- 实现 Explorer 重启后的托盘图标重建
- 实现完整退出清理流程
- 维护核心运行状态：
  - 是否固定控制
  - 是否正在编辑 Fence
  - 是否正在退出
  - 是否已连接 Explorer 桌面

## 产出物

- 原生系统托盘图标
- 可扩展的右键菜单
- 应用生命周期控制入口
- Explorer 重启后的托盘恢复能力

## 验收标准

- 启动后托盘出现应用图标
- 托盘右键菜单可正常打开
- 菜单命令能分发到应用控制器
- 点击退出后执行 `NIM_DELETE`
- 退出后无托盘图标、无窗口、无进程残留

## 风险点

- Explorer 重启会清空托盘图标，需要监听并重建
- 退出流程不能粗暴结束进程，后续还要挂接布局恢复逻辑
- 菜单状态切换必须和真实运行状态一致

## 与主线关系

托盘不是附属功能，它是后续 Fence 编辑、桌面重连、恢复与诊断的统一入口。
