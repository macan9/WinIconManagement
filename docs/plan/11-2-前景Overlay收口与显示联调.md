# 11-2 前景 Overlay 收口与显示联调

## 目标

在真实背景层已经正确显示后，收口前景 Overlay，只让它承担轻量前景提示，而不是再承担真实背景职责。

本阶段重点是：

- 背景层负责背景
- Overlay 负责边框、标题、活动态和轻量提示
- 两层显示一致，不再互相打架

## 本阶段只做什么

- 清理 Overlay 中仍然伪装背景层的职责
- 对齐背景层与 Overlay 的几何、标题和活动态显示
- 收口创建后、激活后、刷新后的前景提示
- 验证 Overlay 不再因为背景职责导致层级和闪动问题放大

## 本阶段不做什么

- 不收口编辑热区命中细节
- 不收口移动、缩放、删除、重命名提交

## 验收标准

- 背景层与 Overlay 的显示位置一致
- 标题、边框、活动态高亮正常
- 创建、刷新、激活切换后，前景提示不会缺帧或错位
- Overlay 已不再承担真实背景填充

## 执行顺序

1. 清理 Overlay 的背景职责。
2. 对齐背景层与前景层显示数据。
3. 回归创建后首次显示、刷新、激活切换。
4. 回归层级与闪动问题是否缩小到可控范围。

这一段完成后，才适合继续收口编辑热区和编辑提交。
