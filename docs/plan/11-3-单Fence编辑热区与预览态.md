# 11-3 单 Fence 编辑热区与预览态

## 目标

把单 Fence 编辑入口收紧成稳定的交互层，但先不急着提交最终数据。

本阶段只关注：

- 哪些区域能编辑
- 预览态是否稳定
- 取消是否能干净回退

## 本阶段只做什么

- 收口活动 Fence 的热区命中
- 收口移动热区、缩放热区、删除热区的可视与命中一致性
- 收口拖拽预览态
- 收口取消编辑时的回退

## 本阶段不做什么

- 不收口最终持久化提交
- 不收口删除后图标恢复规则
- 不收口缩放后的完整图标重排提交

## 验收标准

- 热区显示和命中范围一致
- 移动、缩放、删除入口稳定可达
- 预览态与提交前的几何一致
- 取消操作不会留下脏状态

## 执行顺序

1. 统一活动 Fence 的热区表达。
2. 收口移动、缩放、删除三类入口。
3. 收口预览态与取消回退。
4. 做单 Fence 编辑入口人工回归。
