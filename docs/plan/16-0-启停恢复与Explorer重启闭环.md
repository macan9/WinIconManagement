# 16-0 启停恢复、Explorer 重启与异常恢复闭环

## 目标

把 Explorer 控制主导方案收成真正可靠的桌面工具，补齐启动恢复、退出恢复、Explorer 重启恢复和异常退出保护闭环。

## 开发内容

- 定义恢复策略：
  - 退出时恢复原始桌面布局
  - 退出时保留当前 Fence 布局
  - 异常退出优先进入安全恢复路径
- 启动时读取上次运行状态
- 正常退出时：
  - 停止交互
  - 保存运行时状态
  - 按策略恢复或保留图标布局
- 启动时：
  - 加载 Fence 与 FenceIcons
  - 重新连接 Explorer
  - 重新匹配桌面图标
  - 重新应用 Fence 布局
- Explorer 重启时：
  - 检测桌面句柄失效
  - 重新解析宿主窗口
  - 重新枚举图标
  - 重建 Fence 图标布局
- 异常退出时：
  - 记录恢复标记
  - 下次启动优先恢复安全状态

## 验收标准

- 正常退出后，桌面状态符合当前恢复策略
- 再次启动后，Fence 和图标布局能恢复
- Explorer 重启后，Fence 背景和图标布局能自动重建
- 异常退出后，用户不会误以为桌面图标丢失

## 风险点

- 图标身份匹配不稳会直接影响恢复成功率
- 如果恢复顺序设计错误，可能把正确状态覆盖掉
- Explorer 重启过程中存在窗口短暂无效期，需要容错
