# 03 项目初始化

## 目标

搭建轻量级 C++ Win32 桌面应用骨架，为后续的 Explorer 桌面控制、Fence 背景绘制、图标坐标控制、持久化与恢复能力提供稳定基础。

## 开发内容

- 创建 C++20 Win32 Desktop 项目
- 设置 MSVC 编译参数和 Windows SDK 版本
- 配置 Unicode 编译
- 配置 Per-Monitor DPI Aware
- 实现 `WinMain` 和主消息循环
- 实现单实例运行机制
- 建立基础目录结构：
  - `App`
  - `Tray`
  - `Desktop`
  - `Overlay`
  - `Interaction`
  - `Layout`
  - `Persistence`
  - `Settings`
  - `Infrastructure`
- 添加资源文件：
  - 应用图标
  - 托盘菜单
  - 设置窗口基础资源
- 建立轻量日志模块
- 封装常用 Win32 RAII 资源类型

## 产出物

- 可启动的原生 Win32 `exe`
- 单实例保护
- 主消息循环
- 基础日志文件
- 清晰的工程目录结构

## 验收标准

- 双击 `exe` 后应用能正常启动
- 重复启动不会创建多个实例
- 应用能正常进入和退出 Win32 消息循环
- 日志能写入用户可写目录
- 退出后没有残留进程

## 风险点

- DPI 感知模式必须尽早设定
- 日志和数据库路径不能放在安装目录
- 基础设施如果从一开始不稳定，后续桌面控制与恢复链路会很难排错

## 与主线关系

本阶段不直接处理 Fence 或图标，但它决定后续所有“Explorer 控制主导”能力是否有稳定运行底座。
