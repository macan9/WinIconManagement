# 12-3 Explorer 重启恢复

## 目标

在 Explorer 重启后，自动重新解析桌面窗口、重新枚举图标，并恢复 Fence 背景与图标布局。

## 开发内容

- 检测桌面窗口句柄失效
- 监听 Explorer 重建信号或定时健康检查
- 重新执行 `DesktopWindowResolver`
- 重新枚举桌面图标
- 重新匹配 FenceIcons
- 重新应用 Fence 布局
- 重建托盘图标
- 重绘 Fence 背景层

## 验收标准

- 手动重启 Explorer 后应用不崩溃
- 桌面连接能自动恢复
- Fence 背景重新出现
- 图标布局能重新应用
- 托盘图标能恢复

## 风险点

- Explorer 重启期间窗口句柄会短暂无效
- 过早恢复可能读到不完整图标列表
- 恢复重试需要有上限和日志
