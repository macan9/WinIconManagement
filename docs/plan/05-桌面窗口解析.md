# 05 Explorer 桌面窗口解析

## 目标

稳定找到 Explorer 桌面图标所在的 `SysListView32` 及其上游窗口链，为后续图标枚举、图标移动、Fence 层级控制和 Explorer 重连做准备。

## 开发内容

- 封装 `DesktopWindowResolver`
- 查找桌面相关窗口：
  - `Progman`
  - `WorkerW`
  - `SHELLDLL_DefView`
  - `SysListView32`
- 使用 `EnumWindows` 处理不同桌面窗口层级
- 校验句柄有效性
- 记录窗口类名、句柄、进程 ID、解析路径等诊断信息
- 提供“重新连接桌面”接口
- 支持 Explorer 重启后的重新解析

## 产出物

- `DesktopWindowResolver`
- 桌面 ListView 句柄获取能力
- 桌面宿主拓扑诊断能力
- Explorer 重启后的重连能力

## 验收标准

- 应用启动后能找到桌面 `SysListView32`
- 能明确知道当前用于图标显示的窗口链
- Explorer 重启后能重新找到有效句柄
- 找不到桌面窗口时应用不会崩溃
- 日志中能看到解析路径与失败原因

## 风险点

- 不同 Windows 版本和不同 Explorer 状态下窗口层级可能不同
- 旧句柄失效后不能继续复用
- 多显示器、虚拟桌面和刷新时机可能影响解析结果

## 与主线关系

这是 Explorer 控制主导方案的入口层。后续所有能力都建立在“稳定解析桌面宿主与 ListView”之上。
