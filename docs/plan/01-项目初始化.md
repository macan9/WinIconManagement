# 01 项目初始化

## 目标

搭建轻量级 C++ Win32 桌面应用骨架，为托盘、桌面图标管理、原生浮层和持久化能力提供基础。

## 开发内容

- 创建 C++20 Win32 Desktop 项目
- 设置 MSVC 编译参数和 Windows SDK 版本
- 配置 Unicode 编译
- 配置 Per-Monitor DPI Aware
- 实现 `WinMain` 和主消息循环
- 实现单实例运行机制
- 建立基础目录结构：
  - `App`
  - `Tray`
  - `Desktop`
  - `Overlay`
  - `Interaction`
  - `Layout`
  - `Persistence`
  - `Settings`
  - `Infrastructure`
- 添加资源文件：
  - 应用图标
  - 托盘菜单
  - 设置对话框资源
- 建立轻量日志模块
- 封装常用 Win32 资源 RAII 类型

## 产出物

- 可以启动的原生 Win32 exe
- 单实例保护
- 主消息循环
- 基础日志文件
- 清晰的 C++ 项目目录结构

## 验收标准

- 双击 exe 后应用能正常启动
- 重复启动不会创建多个实例
- 应用能正常进入和退出 Win32 消息循环
- 日志能写入用户可写目录
- 退出后没有残留进程

## 风险点

- DPI 感知模式需要尽早设置
- 日志和数据库路径不能放在程序安装目录
- RAII 封装要覆盖 `HWND`、`HICON`、`HMENU`、`HHOOK`、GDI 对象等资源
