# 01 项目初始化

## 目标

搭建可运行的 Windows 桌面应用骨架，为后续托盘、Overlay、Explorer 图标管理和持久化能力提供基础。

## 开发内容

- 创建 C# / .NET 10 WPF 项目
- 配置单实例运行机制
- 引入基础 NuGet 包：
  - `Serilog`
  - `Microsoft.Data.Sqlite`
  - `Vanara.PInvoke` 或 `Microsoft.Windows.CsWin32`
- 建立基础目录结构：
  - `AppHost`
  - `Desktop`
  - `Overlay`
  - `Layout`
  - `Persistence`
  - `Settings`
  - `Infrastructure`
- 配置应用级日志
- 配置全局异常捕获

## 产出物

- 可以启动的 WPF exe
- 基础日志文件
- 清晰的项目目录结构
- 单实例保护生效

## 验收标准

- 双击 exe 后应用能正常启动
- 重复启动不会创建多个实例
- 应用异常能写入日志
- 退出后进程完整结束

## 风险点

- .NET 10 SDK 和运行环境版本需要统一
- 单实例逻辑不能影响调试体验
- 日志路径需要放在用户可写目录下
