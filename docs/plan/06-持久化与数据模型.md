# 06 持久化与数据模型

## 目标

建立轻量 SQLite 持久化能力，保存应用设置、分组信息、图标位置和后续快照数据。

## 开发内容

- 集成 SQLite C API 或 sqlite3 amalgamation
- 封装 `Database`
- 建立数据库版本号机制
- 创建数据表：
  - `AppSettings`
  - `Fences`
  - `FenceIcons`
  - `Snapshots`
  - `SnapshotIcons`
- 实现基础 Repository：
  - `SettingsRepository`
  - `FenceRepository`
  - `SnapshotRepository`
- 实现事务封装
- 实现设置读写
- 实现分组读写
- 实现图标原始坐标和当前坐标保存
- 设计 `IconIdentity` 第一版生成规则

## 产出物

- SQLite 数据库文件
- C++ 数据访问层
- 设置、分组、图标关系的数据模型
- 数据库版本管理

## 验收标准

- 应用启动时能自动创建数据库
- 应用设置可以保存和读取
- 分组和图标位置可以保存和读取
- 数据库版本可识别
- 数据库连接和语句对象能正确释放

## 风险点

- 图标身份匹配第一版可能不够稳定
- 数据库损坏时需要降级处理
- C API 需要用 RAII 管理 `sqlite3*` 和 `sqlite3_stmt*`
