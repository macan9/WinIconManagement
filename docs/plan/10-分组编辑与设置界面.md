# 10 分组编辑与设置界面

## 目标

提供日常使用所需的基础设置和分组编辑能力。

## 开发内容

- 创建主设置窗口
- 实现固定 / 取消固定切换
- 实现深色 / 浅色切换
- 实现透明度设置
- 实现开机自启动开关
- 支持分组整体拖动
- 支持分组宽高调整
- 支持分组位置和尺寸固定
- 保存分组编辑结果
- 设置窗口显示基础诊断状态

## 产出物

- 主设置窗口
- 分组编辑交互
- 用户设置持久化

## 验收标准

- 托盘菜单可以打开主设置
- 固定状态切换后 Overlay 行为正确变化
- 主题和透明度设置能立即生效并持久化
- 分组拖动和缩放后图标能重新排列
- 开机自启动设置可保存

## 风险点

- 设置 UI 不能阻塞桌面操作
- 分组编辑时要避免误触桌面图标
- 自启动写注册表需要处理权限和路径变化
