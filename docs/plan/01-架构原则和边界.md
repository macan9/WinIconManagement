# 01 Explorer 控制主导桌面分组实现

## 文档定位

本文只定义架构方向和边界。

具体执行顺序以 [02-执行路线图.md](./02-执行路线图.md) 为准；阶段细节以 `03` 到 `15` 的阶段卡片为准。

## 核心判断

本项目不做一套新的桌面图标系统。

正确方向是：

`以 Explorer 原生桌面图标为真实显示层，以应用作为 Fence 容器控制器和图标布局控制器。`

用户看到的是“图标被 Fence 分组组织起来”，但真实图标仍然属于 Windows 桌面。

## 职责边界

### Explorer 桌面控制层

负责：

- 解析桌面窗口拓扑。
- 找到 `SHELLDLL_DefView / SysListView32`。
- 枚举桌面图标。
- 读取图标名称、身份和坐标。
- 批量移动桌面图标。
- Explorer 重启后重新连接。

### Fence 背景层

负责：

- 绘制 Fence 背景、边框、标题。
- 绘制活动态和编辑态提示。
- 绘制框选中的临时矩形。

原则：

- 只做视觉层。
- 不承担桌面图标显示。
- 不大面积接管鼠标输入。

### 小范围交互层

负责：

- 桌面空白区框选起手过滤。
- 选择确认弹层。
- 当前 Fence 的移动、缩放、删除等小热区。

原则：

- 输入范围越小越好。
- 能让 Explorer 原生处理的行为就交还 Explorer。

### 运行时与数据层

负责：

- 保存 Fence 集合。
- 保存图标和 Fence 的归属关系。
- 保存图标原始坐标和当前目标坐标。
- 管理启动、退出、Explorer 重启、异常退出后的恢复策略。

## 不做什么

- 不把 Overlay 当成新的桌面。
- 不把 Overlay 硬塞成桌面图标的父窗口。
- 不依赖全屏 Overlay 承担复杂输入。
- 不自绘桌面图标并替代 Explorer。
- 不让 Fence 背景层破坏任务栏、托盘、普通窗口、桌面右键。

## 最终验收标准

1. 桌面图标仍由 Explorer 原生绘制。
2. 图标可以稳定显示在 Fence 区域之上。
3. Fence 不破坏桌面、任务栏、托盘、普通窗口的正常右键与点击。
4. Fence 创建、移动、缩放、删除、重命名形成闭环。
5. 多 Fence 下图标布局与归属关系可稳定持久化。
6. 启动、退出、Explorer 重启、异常退出后都可恢复。
