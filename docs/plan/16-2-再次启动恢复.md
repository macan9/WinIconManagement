# 16-2 再次启动恢复

## 目标

完成应用再次启动后的恢复闭环，把已保存 Fence 与图标布局重新应用到 Explorer 桌面。

## 开发内容

- 启动时读取上次退出状态
- 重新连接 Explorer 桌面
- 重新枚举当前桌面图标
- 加载全部 Fence
- 加载全部 FenceIcons
- 匹配持久化图标身份与当前桌面图标
- 重新应用 Fence 布局
- 恢复活动 Fence 状态

## 验收标准

- 重新启动后 Fence 背景能恢复
- 重新启动后图标能回到对应 Fence 区域
- 缺失图标不会阻塞整个恢复流程
- 恢复失败有明确日志

## 风险点

- 图标身份匹配不稳会导致恢复错位
- 启动时 Explorer 可能还没完全准备好，需要重试机制
