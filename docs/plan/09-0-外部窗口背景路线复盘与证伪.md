# 09-0 外部窗口背景路线复盘与证伪

## 目标

收口外部窗口背景路线的验证结论：

`普通外部窗口无法稳定实现 Fence 背景在 Explorer 图标下方。`

## 已验证路径

### OverlayWindow

- 能显示在图标上方。
- 适合做前景提示和小范围交互。
- 不适合做真实背景。

### BackgroundWindow 挂 SHELLDLL_DefView

- 子窗能创建和绘制。
- 但 `SysListView32` 会覆盖它。

### BackgroundWindow 挂 WorkerW

- 天然 WorkerW 往往不可见、尺寸异常或不在目标合成层。
- 强行显示或拉伸 WorkerW 会制造全屏白幕，甚至遮住任务栏。

### BackgroundWindow 挂 Progman

- 无法可靠插入到 ListView 背景和图标绘制之间。

## 结论

外部窗口路线已证伪。

后续不再继续尝试：

- 调整外部窗口 Z 序。
- 强行显示或拉伸 WorkerW。
- 把 Progman 当作真实背景宿主。
- 用全屏 Overlay 假装背景。
