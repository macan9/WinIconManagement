# 14-0 多 Fence 运行时与数据管理

## 目标

把单 Fence 模型扩展为多 Fence 运行时。

本阶段不做设置界面，先收住底层运行逻辑和数据操作。

## 验收标准

- 用户可以连续创建多个 Fence。
- 每个 Fence 独立保存位置、尺寸和图标关系。
- 重启后所有 Fence 能重新加载。
- 多 Fence 同时存在时，桌面交互仍保持正常。
