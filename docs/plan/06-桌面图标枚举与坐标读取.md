# 06 桌面图标枚举与坐标读取

## 目标

通过 Explorer 的 `SysListView32` 读取桌面图标列表、名称、身份和坐标，为 Fence 归属、布局、恢复和 Bridge 背景几何提供数据基础。

## 核心能力

- 读取图标数量。
- 读取图标显示名称。
- 读取图标位置。
- 建立稳定的 icon identity。
- 处理跨进程 ListView 数据读取。
- 记录读取失败原因。

## 数据要求

每个图标至少包含：

- `index`
- `displayName`
- `identity`
- `position`
- `sourceListView`

identity 需要尽量稳定，不能只依赖当前 index。

## 与 Bridge 的关系

Bridge 不负责图标枚举。

主程序仍然负责：

- 枚举图标。
- 判断图标是否属于 Fence。
- 计算图标目标坐标。
- 持久化图标归属。

Bridge 只消费 Fence 几何和样式，用于背景绘制。

## 执行步骤

1. 确认 `SysListView32` 句柄有效。
2. 读取 item count。
3. 跨进程读取 item text。
4. 读取 item position。
5. 生成 icon identity。
6. 输出采样日志。
7. Explorer 重启后重新读取。

## 验收标准

- 能读取桌面图标数量。
- 能读取主要图标名称。
- 能读取图标坐标。
- 多次刷新结果稳定。
- Explorer 重启后不会继续使用旧句柄。
- 坐标体系与 Fence bounds、Overlay、Bridge 背景绘制一致。
