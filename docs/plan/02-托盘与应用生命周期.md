# 02 托盘与应用生命周期

## 目标

实现应用常驻托盘、右键菜单和完整退出流程，为后续桌面管理能力提供入口。

## 开发内容

- 接入 WinForms `NotifyIcon`
- 添加系统托盘图标
- 实现托盘右键菜单：
  - 主设置
  - 固定 / 取消固定
  - 退出
- 设计菜单扩展结构
- 实现应用退出清理流程
- 处理托盘图标残留问题
- 维护应用运行状态：
  - 是否固定
  - 是否正在退出
  - 是否已初始化桌面服务

## 产出物

- 系统托盘图标
- 可扩展右键菜单
- 稳定退出流程

## 验收标准

- 启动后托盘出现应用图标
- 右键菜单可以正常打开
- 点击退出后托盘图标消失
- 退出后没有残留进程
- 退出流程可以被后续恢复图标逻辑挂接

## 风险点

- WPF 与 WinForms 托盘生命周期需要统一释放
- 异常退出时可能出现托盘图标短暂残留
- 后续恢复图标逻辑可能让退出流程变长，需要避免 UI 卡死
