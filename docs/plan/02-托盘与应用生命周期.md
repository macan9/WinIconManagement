# 02 托盘与应用生命周期

## 目标

实现原生系统托盘、右键菜单和应用生命周期管理，为常驻轻量工具提供入口。

## 开发内容

- 使用 `Shell_NotifyIcon` 添加托盘图标
- 封装 `TrayIcon`
- 注册托盘消息窗口
- 实现托盘右键菜单：
  - 主设置
  - 固定 / 取消固定
  - 暂停管理
  - 恢复原始布局
  - 退出
- 统一菜单 command id 分发
- 实现 Explorer 重启后的托盘图标重建
- 实现完整退出清理流程
- 维护应用运行状态：
  - 是否固定
  - 是否暂停管理
  - 是否正在退出
  - 是否已连接桌面窗口

## 产出物

- 原生系统托盘图标
- 可扩展右键菜单
- 应用生命周期控制器
- Explorer 重启后托盘恢复能力

## 验收标准

- 启动后托盘出现应用图标
- 右键菜单可以正常打开
- 菜单命令能分发到应用控制器
- 点击退出后调用 `NIM_DELETE`
- 退出后没有托盘图标、窗口和进程残留

## 风险点

- Explorer 重启会清空托盘图标，需要监听并重新添加
- 退出流程后续会挂接图标恢复逻辑，不能直接粗暴结束进程
- 托盘消息窗口需要避免意外显示和抢焦点
