# 11-1 真实 Fence 显示与编辑态联调

## 文档定位

本文承接 `09` 和 `10`。

- `09` 只验证 Overlay 无侵入存在。
- `10` 负责真正创建出第一个 Fence。
- 本阶段负责在“已经有真实 Fence”的前提下，验证 Overlay 与真实 Fence 的显示和编辑态联调。

## 目标

在已有真实 Fence 的情况下，补完原先 `09` 中无法独立验收的部分。

## 验收内容

- Fence 背景、边框、标题显示正确
- 活动态高亮正确
- 当前活动 Fence 与显示状态一致
- 编辑态热区位置正确
- 顶部标题栏可作为移动热区
- 删除按钮和缩放柄位置正确
- Fence 在多显示器下显示位置正确
- Explorer 重连后 Fence 背景仍能重新锚定到正确层级

## 执行顺序

1. 通过 `10` 创建第一个真实 Fence。
2. 验证 Fence 背景、边框、标题显示。
3. 验证活动态高亮。
4. 验证编辑热区位置和范围。
5. 验证多显示器显示位置。
6. 验证 Explorer 重连后的层级恢复。

## 通过标准

- 真实 Fence 可以稳定显示。
- 编辑态视觉和热区与当前活动 Fence 一致。
- 多显示器和重连后不丢失层级关系。

## 与主线关系

这是 `09` 和 `11-0` 之间的桥接阶段。

没有它，`09` 的后半部分会一直悬空，`11-0` 的编辑联调也缺少真实场景支撑。
