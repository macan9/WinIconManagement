# 02 执行路线图

## 当前判断

`03-08` 是基础底座。

`09` 只负责收口外部窗口背景路线：它已经证明普通外部窗口不能稳定实现“Fence 背景在 Explorer 图标下方”。

因此当前不应该先做 Overlay 收口或框选创建单 Fence，而应该先进入 `10` 的 Explorer Bridge 进程内背景绘制。

## A. `03-08` 基础底座

目标：

- 应用可启动、隐藏、退出。
- 能解析 Explorer 桌面窗口。
- 能读取和移动桌面图标。
- 能保存 Fence 和 FenceIcon 数据。

这些阶段不重新做，遇到缺口时局部回补。

## B. `09` 外部窗口背景路线收口

目标：

- 记录 `OverlayWindow / BackgroundWindow / WorkerW / Progman` 路线为什么不能作为真实背景方案。
- 保留安全止血代码。
- 没有安全宿主时 fail closed。

子阶段：

1. `09-0` 外部窗口背景路线复盘与证伪。
2. `09-1` 外部窗口背景路线止血与收口。

完成后不再继续扩大外部窗口方案。

## C. `10` Explorer Bridge 进程内背景绘制

目标：

让 Fence 背景绘制发生在 Explorer 进程内，而不是通过外部窗口压层级。

执行顺序：

1. `10-0` Explorer Bridge 总览与边界。
2. `10-1` Bridge DLL 注入与生命周期。
3. `10-2` Bridge IPC 与 Fence 数据同步。
4. `10-3` Explorer 内 ListView 背景绘制 PoC。
5. `10-4` Explorer 内绘制稳定化与回退。

完成条件：

- Bridge 可注入、可日志、可清理。
- 主程序能把 Fence 数据发送给 Bridge。
- Explorer 内背景绘制能显示在图标下方。
- 退出和 Explorer 重启后不污染桌面状态。

## D. `11` Overlay 无侵入显示与输入边界

目标：

- Overlay 只做前景提示和小范围输入。
- Overlay 不做真实背景。
- Overlay 不遮挡任务栏、托盘、普通窗口和桌面右键。

## E. `12` 框选创建单个 Fence

目标：

在真实背景路径稳定后，完成第一个用户可见闭环：

`框选图标 -> 创建 Fence -> 移动图标 -> 保存关系 -> Bridge 绘制背景 -> Overlay 显示前景提示`

## F. `13` 单 Fence 前景 Overlay 与编辑

目标：

- 收口标题、边框、活动态、删除按钮、缩放手柄。
- 收口移动、缩放、删除、重命名提交。

## G. `14-17` 产品化

- `14` 多 Fence。
- `15` 编辑与设置界面。
- `16` 启停恢复与 Explorer 重启恢复。
- `17` 稳定性增强。
