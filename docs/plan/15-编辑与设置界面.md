# 15 编辑与设置界面

## 目标

在多 Fence 运行时稳定后，提供原生 Win32 设置窗口与分组管理界面，把底层能力变成可管理、可配置、可编辑的产品功能。

## 开发内容

- 创建原生设置窗口
- 使用 Dialog 或 Property Sheet 管理设置页
- 提供全局设置：
  - 固定控制 / 取消固定控制
  - 主题
  - 透明度
  - 开机自启动
  - 恢复策略
- 提供 Fence 列表视图
- 支持：
  - 查看全部 Fence
  - 选择当前编辑 Fence
  - 重命名 Fence
  - 删除 Fence
  - 调整显示顺序
  - 查看 Fence 内图标数量
- 提供基础诊断信息：
  - 桌面连接状态
  - 当前 Fence 数量
  - 托管图标数量
  - 数据库路径
  - 最近错误摘要

## 产出物

- 主设置窗口
- Fence 列表管理界面
- 基础全局设置持久化
- 诊断信息展示

## 验收标准

- 托盘菜单可以打开主设置
- 设置窗口打开后资源占用保持轻量
- 用户可以查看并管理多个 Fence
- 全局设置修改后可立即生效并持久化
- 设置窗口不会阻塞桌面主操作链

## 风险点

- 设置窗口不能反向破坏桌面控制主链
- Fence 列表和运行时状态必须保持一致
- 如果缺少明确的当前 Fence 概念，界面会失控

## 与主线关系

本阶段把前面的底层能力包装成可使用、可诊断的正式产品入口。
