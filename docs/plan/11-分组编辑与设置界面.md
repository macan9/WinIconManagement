# 10 分组编辑与设置界面

## 目标

使用原生 Win32 设置窗口提供日常使用所需的基础设置和分组编辑能力。

从本阶段开始，设置与编辑界面必须明确支持“多个矩形分组”，不能只服务单分组场景。

## 开发内容

- 创建原生设置对话框
- 使用 Dialog 或 Property Sheet 管理设置页
- 实现固定 / 取消固定切换
- 实现暂停管理切换
- 实现深色 / 浅色切换
- 实现透明度设置
- 实现开机自启动开关
- 支持分组整体拖动
- 支持分组宽高调整
- 支持分组位置和尺寸固定
- 保存分组编辑结果
- 设置窗口显示基础诊断状态：
  - 桌面连接状态
  - 托管图标数量
  - 数据库路径
  - 最近错误

## 多矩形要求

- 设置窗口要能列出全部分组
- 用户可以选择当前编辑的分组
- 至少支持以下多分组操作：
  - 查看分组列表
  - 选择当前分组
  - 重命名分组
  - 删除分组
  - 调整显示顺序
  - 查看该分组内图标数量
- 后续视觉设置应支持“全局默认值”和“单分组覆盖值”两层

## 产出物

- 原生主设置窗口
- 多分组编辑交互
- 用户设置持久化
- 基础诊断信息

## 验收标准

- 托盘菜单可以打开主设置
- 设置窗口打开后资源占用仍保持轻量
- 固定状态切换后浮层行为正确变化
- 主题和透明度设置能立即生效并持久化
- 分组拖动和缩放后图标能重新排列
- 用户可以在设置窗口中切换和管理多个分组
- 开机自启动设置可保存

## 风险点

- 原生控件开发成本高于高级 UI 框架
- 设置窗口不能阻塞桌面操作
- 如果没有分组列表和当前分组概念，后续多矩形能力会在设置页失控
