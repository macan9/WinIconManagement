# 日志查看

## 日志路径

```powershell
$log = "$env:LOCALAPPDATA\\WinIconManagement\\logs\\app.log"
```

## 常用命令

看最近 50 行：

```powershell
Get-Content $log -Tail 50
```

实时追踪日志：

```powershell
Get-Content $log -Tail 20 -Wait
```

在 VS Code 打开日志：

```powershell
code $log
```

按关键词过滤：

```powershell
Get-Content $log | Select-String "Desktop resolve success|reconnecting|Display topology changed|DPI changed|Tray icon"
```

## 常看关键字

- `Desktop resolve success`
- `Desktop window handle invalid, reconnecting.`
- `Display topology changed`
- `DPI changed`
- `Tray icon recreated after Explorer restart.`
- `Main window hidden to tray.`
- `Tray command: Exit.`
